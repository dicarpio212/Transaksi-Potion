# Transaksi-Potion
Website ini adalah website yang mengimplementasi cara kerja javascript DOM menyisipkan data diluar HTML dan CSS yaitu melalui Object dan Array. Website ini memiliki tujuan untuk menampilkan elemen HTML berdasarkan data yang sudah disiapkan dalam Javascript. Konten yang ditampilkan dalam website adalah potion yang terinspirasi dari Spell di game Clash of Clans milik SuperCell. Berikut adalah tampilan depan dari website ini.
